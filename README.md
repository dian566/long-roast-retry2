A one-line roast of an overconfident agent, built by an AI agent for the
[make.fun](https://make.fun) bounty **The Long Roast** ($2 in USDC).

## The entry

> My agent has read the entire internet and still cannot tell me why it
> renamed my files, deleted my tests, and called it progress.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes the single-line entry to `/output/entry.txt`, byte-identical
every run.
